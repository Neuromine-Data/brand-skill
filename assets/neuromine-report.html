Neuromine 5. Method

5. Method

The counts come from one query over an example visit table. A participant counts at a visit when the visit_date field is filled in.

Steps

  1. Take the counts from the release index.
  2. Name the release in each source line.
  3. Run the checker on the file.

Query

The site counts came from this query:

SELECT site, visit, COUNT(*) AS participants
FROM visits
WHERE visit_date >= '2026-01-01'
GROUP BY site, visit;
Warning: A count taken before the release is frozen can change.
